# DateInput

Date picker with calendar dropdown

**Category:** forms

## Import

```tsx
import { DateInput, DateRangeInput } from 'jind-ui-kit';
import type { DateInputProps, DateRangeInputProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `value` | `Date \| null` |
| `onChange` | `(date: Date \| null) => void` |
| `placeholder` | `string` |
| `disabled` | `boolean` |
