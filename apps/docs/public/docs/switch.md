# Switch

Toggle switch for boolean values

**Category:** forms

## Import

```tsx
import { Switch } from 'jind-ui-kit';
import type { SwitchProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `checked` | `boolean` |
| `defaultChecked` | `boolean` |
| `disabled` | `boolean` |
| `onChange` | `(checked: boolean) => void` |
| `label` | `string` |
| `borderRadius` | `number` |
