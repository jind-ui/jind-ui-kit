# Carousel

Horizontal content slider with arrows and dots

**Category:** content

## Import

```tsx
import { Carousel, type CarouselProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `children` | `ReactNode` |
| `autoPlay` | `boolean` |
| `interval` | `number` |
| `showDots` | `boolean` |
| `showArrows` | `boolean` |
| `loop` | `boolean` |
| `slidesToShow` | `number` |
| `gap` | `number` |
