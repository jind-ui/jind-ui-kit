# HoverCard

Rich content card appearing on hover

**Category:** overlay

## Import

```tsx
import { HoverCard } from 'jind-ui-kit';
import type { HoverCardProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `trigger` | `ReactNode` |
| `children` | `ReactNode` |
| `side` | `'top' \| 'bottom'` |
| `align` | `'start' \| 'center' \| 'end'` |
| `openDelay` | `number` |
| `closeDelay` | `number` |
