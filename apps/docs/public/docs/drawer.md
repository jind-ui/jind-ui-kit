# Drawer

Slide-out panel from screen edge

**Category:** overlay

## Import

```tsx
import { Drawer } from 'jind-ui-kit';
import type { DrawerProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `open` | `boolean` |
| `onClose` | `() => void` |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` |
| `width` | `number \| string` |
| `height` | `number \| string` |
| `title` | `string` |
| `children` | `ReactNode` |
| `footer` | `ReactNode` |
