# Button

Polymorphic button with variant, size, loading, and icon support

**Category:** buttons

## Import

```tsx
import { Button } from 'jind-ui-kit';
import type { ButtonProps, ButtonOwnProps, IconAnimation } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `variant` | `'primary' \| 'secondary'` |
| `size` | `'md' \| 'sm'` |
| `iconLeft` | `ReactNode` |
| `iconRight` | `ReactNode` |
| `iconActive` | `boolean` |
| `iconAnimation` | `IconAnimation` |
| `disabled` | `boolean` |
| `fullWidth` | `boolean` |
| `pressEffect` | `PressEffect` |
| `as` | `ElementType` |
| `children` | `ReactNode` |
