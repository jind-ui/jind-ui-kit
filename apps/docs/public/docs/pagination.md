# Pagination

Page navigation with numbered pages

**Category:** navigation

## Import

```tsx
import { Pagination } from 'jind-ui-kit';
import type { PaginationProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `page` | `number` |
| `totalPages` | `number` |
| `onPageChange` | `(page: number) => void` |
| `siblingCount` | `number` |
| `showEdges` | `boolean` |
