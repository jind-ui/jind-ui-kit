# Select

Dropdown select with custom styling

**Category:** forms

## Import

```tsx
import { Select } from 'jind-ui-kit';
import type { SelectProps, SelectOption } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `value` | `string` |
| `defaultValue` | `string` |
| `placeholder` | `string` |
| `options` | `SelectOption[]` |
| `disabled` | `boolean` |
| `onChange` | `(value: string) => void` |
