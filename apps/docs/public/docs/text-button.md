# TextButton

Minimal text-style button for inline actions

**Category:** buttons

## Import

```tsx
import { TextButton } from 'jind-ui-kit';
import type { TextButtonProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `variant` | `'plain' \| 'link' \| 'dropdown' \| 'sort'` |
| `disabled` | `boolean` |
| `pressEffect` | `PressEffect` |
| `chevronSide` | `'left' \| 'right'` |
| `children` | `ReactNode` |
| `onClick` | `React.MouseEventHandler<HTMLButtonElement>` |
