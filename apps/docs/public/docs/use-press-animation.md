# usePressAnimation

## Options

| Option | Type |
|--------|------|
| `effect` | `PressEffect` |
| `disabled` | `boolean` |

## Returns

| Property | Type |
|----------|------|
| `pressed` | `boolean` |
| `onMouseDown` | `() => void` |
| `onMouseUp` | `() => void` |
| `onMouseLeave` | `() => void` |

## Import

```tsx
import { usePressAnimation } from 'jind-ui-kit';
```
