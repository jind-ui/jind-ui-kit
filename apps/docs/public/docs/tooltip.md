# Tooltip

Floating tooltip on hover or focus

**Category:** overlay

## Import

```tsx
import { Tooltip } from 'jind-ui-kit';
import type { TooltipProps, TooltipPlacement } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `content` | `ReactNode` |
| `placement` | `TooltipPlacement` |
| `delay` | `number` |
| `children` | `ReactElement` |
