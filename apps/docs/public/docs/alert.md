# Alert

Inline notification block with tone variants and dismiss

**Category:** feedback

## Import

```tsx
import { Alert } from 'jind-ui-kit';
import type { AlertProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `tone` | `Tone` |
| `title` | `string` |
| `children` | `ReactNode` |
| `icon` | `string` |
| `onDismiss` | `() => void` |
| `variant` | `'subtle' \| 'solid'` |
