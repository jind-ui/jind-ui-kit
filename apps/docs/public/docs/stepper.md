# Stepper

Multi-step progress indicator

**Category:** navigation

## Import

```tsx
import { Stepper } from 'jind-ui-kit';
import type { StepperProps, StepItem } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `steps` | `StepItem[]` |
| `activeStep` | `number` |
| `orientation` | `'horizontal' \| 'vertical'` |
| `onStepClick` | `(index: number) => void` |
