# Motion

Animation wrapper using Framer Motion

**Category:** animation

## Import

```tsx
import { Motion, motion, AnimatePresence } from 'jind-ui-kit';
import type { MotionProps, MotionPreset } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `show` | `boolean` |
| `preset` | `MotionPreset` |
| `duration` | `number` |
| `delay` | `number` |
| `children` | `ReactNode` |
| `as` | `ElementType` |
| `layout` | `boolean` |
| `onAnimationComplete` | `() => void` |

## NPM Dependencies

- `motion@*`
