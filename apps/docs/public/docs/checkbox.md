# Checkbox

Checkbox with label and indeterminate state

**Category:** forms

## Import

```tsx
import { Checkbox } from 'jind-ui-kit';
import type { CheckboxProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `checked` | `boolean` |
| `defaultChecked` | `boolean` |
| `disabled` | `boolean` |
| `onChange` | `(checked: boolean) => void` |
| `label` | `string` |
| `indeterminate` | `boolean` |
