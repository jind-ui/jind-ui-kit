# ButtonGroup

Groups buttons with connected or spaced layout

**Category:** buttons

## Import

```tsx
import { ButtonGroup, type ButtonGroupProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `children` | `ReactNode` |
| `size` | `'sm' \| 'md'` |
| `variant` | `'primary' \| 'secondary'` |
| `orientation` | `'horizontal' \| 'vertical'` |
| `attached` | `boolean` |
| `divider` | `boolean` |
| `dividerStyle` | `CSSProperties` |

## Dependencies

- button
