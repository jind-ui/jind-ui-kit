# NativeSelect

Browser-native select with custom styling

**Category:** forms

## Import

```tsx
import { NativeSelect } from 'jind-ui-kit';
import type { NativeSelectProps, NativeSelectOption } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `options` | `NativeSelectOption[]` |
| `value` | `string` |
| `defaultValue` | `string` |
| `onChange` | `(value: string) => void` |
| `placeholder` | `string` |
| `disabled` | `boolean` |
| `size` | `'sm' \| 'md' \| 'lg'` |
| `label` | `string` |
| `error` | `string` |
| `fullWidth` | `boolean` |
