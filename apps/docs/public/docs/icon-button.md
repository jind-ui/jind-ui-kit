# IconButton

Icon-only button with tooltip support

**Category:** buttons

## Import

```tsx
import { IconButton } from 'jind-ui-kit';
import type { IconButtonProps, IconButtonOwnProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `name` | `string` |
| `variant` | `'tile' \| 'ghost'` |
| `tone` | `'default' \| 'danger'` |
| `size` | `'lg' \| 'md' \| 'sm'` |
| `disabled` | `boolean` |
| `label` | `string` |
| `pressEffect` | `PressEffect` |
| `as` | `ElementType` |
