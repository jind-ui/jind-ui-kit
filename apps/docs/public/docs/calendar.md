# Calendar

Calendar grid for date picking

**Category:** utility

## Import

```tsx
import { Calendar } from 'jind-ui-kit';
import type { CalendarProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `year` | `number` |
| `month` | `number` |
| `selected` | `Date` |
| `outlined` | `Date` |
| `onSelect` | `(date: Date) => void` |
| `onClear` | `() => void` |
