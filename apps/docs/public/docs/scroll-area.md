# ScrollArea

Custom styled scrollbar wrapper

**Category:** layout

## Import

```tsx
import { ScrollArea } from 'jind-ui-kit';
import type { ScrollAreaProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `children` | `ReactNode` |
| `maxHeight` | `number \| string` |
| `orientation` | `'vertical' \| 'horizontal' \| 'both'` |
| `scrollbarSize` | `number` |
