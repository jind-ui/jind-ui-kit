# InputGroup

Input with prefix/suffix addons and inline elements

**Category:** forms

## Import

```tsx
import { InputGroup } from 'jind-ui-kit';
import type { InputGroupProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `children` | `ReactNode` |
| `leftAddon` | `ReactNode` |
| `rightAddon` | `ReactNode` |
| `leftElement` | `ReactNode` |
| `rightElement` | `ReactNode` |
| `size` | `'sm' \| 'md' \| 'lg'` |
