# Banner

Full-width notification banner with variants

**Category:** overlay

## Import

```tsx
import { Banner } from 'jind-ui-kit';
import type { BannerProps } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `tone` | `Tone` |
| `children` | `ReactNode` |
| `icon` | `string` |
| `action` | `ReactNode` |
| `onDismiss` | `() => void` |
| `position` | `'top' \| 'bottom' \| 'inline'` |
