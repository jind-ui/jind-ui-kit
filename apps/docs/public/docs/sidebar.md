# Sidebar

App layout sidebar with sections and collapse

**Category:** navigation

## Import

```tsx
import { Sidebar } from 'jind-ui-kit';
import type { SidebarProps, SidebarSection, SidebarItem } from 'jind-ui-kit';
```

## Props

| Prop | Type |
|------|------|
| `sections` | `SidebarSection[]` |
| `header` | `ReactNode` |
| `footer` | `ReactNode` |
| `collapsed` | `boolean` |
| `onCollapsedChange` | `(collapsed: boolean) => void` |
| `width` | `number` |
| `collapsedWidth` | `number` |
